## Skill trigger: `common-troubleshooting`

Invoke the `common-troubleshooting` skill when:
- The issue does not clearly map to a specific skill above
- Multiple symptoms span several areas (storage + performance + connections)
- The user needs a structured investigation methodology
- You need to define the problem statement and form hypotheses before diving into specific checks
- The triage skill has recommended `common-troubleshooting` as the entry point
- A postmortem or root cause analysis is being conducted
